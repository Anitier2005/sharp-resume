# 产品运营该怎么选

> 产品界定长期价值、从 0 到 1，要懂设计前端后端；运营创造短期价值、让产品活下去，从 1 到 100。

## 产品和运营到底差在哪

一、产品负责界定和提供长期用户价值，管一个产品从 0 到 1，确定功能怎么实现。
二、例子：抖音要做一个续火花功能，产品要决定它放在视频页、主页还是聊天框，然后对接 UI 出设计稿、找前端做界面、找后端调连续登录的数据。
三、所以产品经理必须懂 UI 设计、前端和后端，知道功能怎么落地；而且不光要能用，还要好用。
四、运营负责创造短期用户价值，并协助产品完善长期价值——让一个已经成型的产品活下去、活得很好，从 1 到 100。
五、同样是抖音的续火花：运营要制定活动规则、让更多人用起来并持续用下去。
六、一句话区别：产品决定「做成什么样」，运营决定「怎么让人用起来」。
