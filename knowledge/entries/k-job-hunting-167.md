# 讲一些职场黑话

> 储备干部是先储备着、6000–8000 就是 6000、氛围好有下午茶就是要经常加班、抗压能力强就是要挨骂。

## 招聘黑话的翻译表

一、储备干部 = 先给你储备着，看他干不干；写「高薪」那就是低薪工作。
二、成长空间大 = 没人带你，自求多福；工资上不封顶 = 底薪很低全靠提成。
三、结果导向 = 出了事算你的，做出成绩算领导的；接受零经验小白 = 要割你韭菜。
四、6000–8000 就是 6000；3000–8000 可能连 2000 都没有；应届生优先 = 只要有经验的。
五、福利是五险一金 = 没有福利；公司氛围好有下午茶 = 要经常加班；公司年轻化 = 人员流动性大、留不住老人。
六、挖掘客户需求 = 不停打骚扰电话；扁平化管理 = 老板也不知道怎么管；抗压能力强 = 要挨骂；需要团队协作能力 = 做好背锅的准备。
