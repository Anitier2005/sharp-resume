# 技能目录

这里的每个 `.md` 都会被自动编进打包产物，并在对话时附加在 system 提示词之后。
新增一个文件就是新增一个「技能」——不需要改代码、不需要注册。

约定：

- 文件名就是技能名（`rewrite-star.md` → 「rewrite-star」）
- 开头用一行 `# 标题` 说明这个技能干什么
- 正文写「什么时候用 / 怎么做 / 输出格式」
- 写完之后刷新界面即可生效（dev 模式 vite 会热更新；发布版要重新打包）

已内置：

| 文件 | 用途 |
|---|---|
| `star.md` | 把经历改写成 STAR 结构 |
| `jd-align.md` | 对照 JD 找出缺口与匹配点 |
| `tone.md` | 统一措辞风格（动词开头、去形容词、量化） |
