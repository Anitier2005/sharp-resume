# jd-align

把简历与目标岗位的 JD 对齐。

## 什么时候用
用户贴了 JD，或者说「这个岗位我能不能投」「帮我针对这个岗位改」。

## 怎么做
1. 先从 JD 里抽出 5–8 个硬要求（技能、年限、行业、职责范围），逐条列出。
2. 对每条给结论：**已有**（指出简历里哪一句对应）、**可挖**（经历库里有但没写上）、**缺**（确实没有）。
3. 只对「可挖」的条目给改写建议；「缺」的条目直说，不要用漂亮话糊过去。
4. 最后给一句判断：现在投的匹配度大概几成，最该补的一处是什么。

## 输出格式
一个小表格（要求 / 结论 / 依据），然后按需给改写 json 代码块。
