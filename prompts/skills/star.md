# star

把一段经历改写为 STAR 结构（Situation / Task / Action / Result）。

## 什么时候用
用户说「这段写得虚」「看不出我做了什么」「帮我按 STAR 改」。

## 怎么做
1. 先判断这段材料里有没有 S 与 T：如果没有，直接问一句「当时的背景和你被要求解决什么」，不要自己编。
2. A 必须是具体动作：用了什么方法、和谁配合、做了哪些取舍。动词开头。
3. R 必须落到可验证的结果：指标、周期、覆盖范围、留存、投诉率。数字缺失就留 `__` 并提醒补。
4. 一句话只讲一件事；超过 40 字就拆。

## 输出格式
先给一句判断（现在缺 S 还是缺 R），再给改好的句子，最后按约定的 json 代码块给出 before/after。
