# tone

统一简历措辞风格。

## 什么时候用
用户说「读起来不一致」「帮我统一一下语气」，或者你在改写时发现整页风格混杂。

## 规则
1. 每条以动词开头（主导 / 搭建 / 收敛 / 迁移 / 推动），不用「负责」「参与」开头。
2. 删掉无信息量的形容词：丰富的、较强的、优秀的、全面的。
3. 数字优先于形容：不说「大幅提升」，说「从 2 周缩到 3 天」。
4. 一条一句话，不嵌套从句；中英混排时术语保持原文（Figma、埋点、灰度）。
5. 同一页内不要重复同一个动词超过两次。

## 输出格式
按约定的 json 代码块给出 before/after；一次最多改 8 句，多了先问用户要不要全改。
